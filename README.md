# CrankBoy Manager Tap

Official Homebrew tap for [CrankBoy Manager](https://github.com/CrankBoyHQ/crankboy-manager) and related tools.

## Installation

You can install CrankBoy Manager directly via Homebrew:

```bash
brew tap CrankBoyHQ/tap
brew install crankboy-manager
```

## Updating

To update to the latest version:

```bash
brew upgrade crankboy-manager
```

## Troubleshooting

If you run into any issues or want to report a bug, please open an issue on the [CrankBoy Manager repository](https://github.com/CrankBoyHQ/crankboy-manager/issues).
